# Screenshots

The main README references three images. Filenames must match exactly:

| File | What to capture |
| --- | --- |
| `folder-view.png` | A folder comparison showing a mix of statuses — identical, differing, and only-on-one-side rows |
| `file-view.png` | A side-by-side file diff with visible changes, the centre copy chevrons, and the minimap |
| `settings.png` | The Settings modal, with the exclude list and the .gitignore toggle visible |

On macOS, `Cmd+Shift+4` then `Space` captures a single window with its shadow.
Capture at the default 1300×800 window size or larger; GitHub scales them down.
